# Packaged-release validation

Executed on the Linux homelab, NVIDIA RTX 5060 Ti 16 GB. No retraining and no camera application were involved. The numerical package was copied into a separate directory and its own release archives were extracted with the shipped downloader. All original training checkpoints were retained.

## Checks completed

- P1 and Q4 general verification: three meshes × four electromagnetic regimes; explicit element assembly, coil solution and five LED samples. P1 Table I errors and Table II values agree at the printed precision. Records: `fem/P1.json`, `fem/Q4.json`.
- Figure 2: four P1 cases solved anew. Normalized free-equation residuals below 1e-10. Record: `fem/benchmarks.json`.
- Interchangeable ruler solver: affine patch, manufactured convergence, Q4 interpolation/gradients, two scenes × three local mesh sizes × two element families. P1 output agrees exactly with the training teacher implementation. Record: `fem/ruler.json`.
- Dataset audit: 1,143 images; train/validation/test = 926/99/118, 82 disjoint groups. Image, mask, teacher and model hashes checked; all 6,583 archived research files checked after extraction. Record: `assets.json`.
- Metric replay from stored predictions: all 72 paper accuracy entries reproduce within 4e-8 LED-equivalent V (FP32 LUT versus NumPy interpolation rounding).
- Fresh checkpoint inference: physical ensemble and eight RGB models evaluated again on all 118 test images. **All 72 error entries are exactly equal to the recorded values** in this environment. Record: `inference/accuracy.json`.
- Parameter counts agree for all nine methods. The repeated timing run is in `inference/timing_recheck.json`; the paper retains its original homelab measurements in `reference/inference_homelab.json`. Small timing differences reflect execution variability and do not replace the reference measurements.
- Table III regenerated by `figures/table3.py` is byte-identical to the manuscript table.
- Figures 1, 4 and 5 regenerated from the packaged inputs. Figure 4 PNG is pixel-identical. Figure 5 differences are confined to rendering of mesh lines; numerical maps, common scales and layouts are unchanged. Reference compositions remain available. All twelve displayed predicted-potential maps were independently restored from checkpoints and agree exactly with the packaged numeric inputs.
- All twelve displayed P1 meshes were solved anew and agree exactly with saved teacher fields and node/triangle counts. Record: `figure5_meshes.json`.
- PCA display-panel exporter completed for the two encoders and all four arms. Its raw 224×224 tiles precede the 255×255 publication rasterization; those raster images are not expected to be byte-identical. Both use the same fixed training-only projection, crop and color policy. `figure_inputs_recheck.json` records that resolution distinction and exact numeric-field comparison.
- The corresponding manuscript compiles to eight pages, without LaTeX warnings or overfull boxes. Its equations and result values were preserved; the Q4 availability statement and public repository link were corrected.

## Scope

The FEM-based targets and LED-equivalent voltage are the study's reference definition, not an independent voltage measurement. Reserved recorded videos were previously inspected; this is diagnostic evaluation. Geometry-assisted methods receive reviewed masks, while dense RGB models do not. CPU FEM and GPU model timing are distinct. No macOS timing or cross-platform comparison is part of this release's reported metrics.

The repository contains source, meshes, metadata and reference figure inputs; larger datasets, weights, geometry caches and predictions are separate release assets. `asset_manifest.json` identifies their hashes. `packaging_changes.json` records source portability substitutions without changing learned tensors or the original frozen checkpoint provenance.
