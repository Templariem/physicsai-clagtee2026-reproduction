# Homelab verification

`P1.json` and `Q4.json`: three meshes, four regimes and coil/LED samples from the explicit general solver. `benchmarks.json`: the four P1 classical benchmark cases with normalized free-equation residual checks. `ruler.json`: P1/Q4 manufactured convergence, patch/interpolation/gradient checks and twelve coil/ruler solves; includes exact regression against the training P1 implementation. All runs used the Linux homelab CPU. Neural metrics and GPU timing belong to the separate reproduction package. No models were trained for this verification.
